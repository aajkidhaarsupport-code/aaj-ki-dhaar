SQL Editor → New query → `schema.sql` पूरा पेस्ट → Run → "Success"। (पिन, ऑर्डर, वॉलेट कुछ नहीं बदलता।)

## स्टेप 2 — GitHub में फाइलें (सब पुरानी की जगह)
`index.html`, `sw.js`, `manifest.json`, `config.js`, `pwa.js`, पाँचों `.png` आइकन, और `photos` फोल्डर (अगर फोटो डाली हैं)।

## स्टेप 3 — Render डिप्लॉय के बाद Ctrl+Shift+R। फोन में ऐप बंद करके दो बार खोलें।

## नया क्या है
- **प्रोडक्ट पेज** (फोटो पर टैप): गैलरी, रेटिंग, MRP/बचत, 📅 सब्सक्राइब व 🛒 एक बार लें बटन, ऑफ़र/कूपन, रेफ़र कार्ड, "भरोसा क्यों" वाला हिस्सा, ग्राहक रिव्यू (लिखना भी)।
- **कूपन**: ऑर्डर में कोड डालें, छूट और देय राशि बिल में दिखती है (सर्वर पर जाँचा जाता है)। एडमिन → 🎟️ कूपन में % या ₹ वाले कूपन बनाएँ: न्यूनतम ऑर्डर, अधिकतम छूट, आख़िरी तारीख, "सिर्फ़ पहला ऑर्डर", ऐप में दिखाएँ/छुपाएँ, चालू/बंद।
- **रेफ़र-एंड-अर्न**: हर ग्राहक का अपना कोड (मेरे ऑर्डर → डैशबोर्ड)। दोस्त साइन-अप पर कोड डाले (या लिंक `?ref=कोड` से अपने-आप) और उसका पहला ऑर्डर डिलीवर हो (एडमिन "डिलीवर" दबाए) → दोनों के वॉलेट में बोनस। राशि एडमिन → सेटिंग्स → "रेफ़र बोनस" (अभी ₹50; 0 = बंद)।
- **रिव्यू**: सिर्फ़ वही दे सकते हैं जिनका प्रोडक्ट डिलीवर हो चुका है। एडमिन → 💬 फीडबैक के नीचे रिव्यू दिखते हैं, ग़लत रिव्यू "छुपाएँ"।
- **भरोसे की लाइनें**: एडमिन → सेटिंग्स में अपनी असली बातें लिखें (हर लाइन अलग)। जो अभी भरी हैं, वे सिर्फ़ नमूना हैं — अपने हिसाब से बदलें।
- ऑर्डर में बिल: कीमत × मात्रा, MRP पर बचत, कूपन, देय राशि।
- फोटो: GitHub `photos` में `cow_milk-1.jpg … -5.jpg` जैसे नाम से डालें (सूची photos/README.txt में)।
